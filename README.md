# Lab 6: Implementation of Perceptron Learning Algorithm

## Aim

To implement the Perceptron Learning Algorithm using Python.

## Dataset

The Iris dataset provided by Scikit-learn.

## Libraries Used

* NumPy
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn

## Procedure

1. Import the required libraries.
2. Load the Iris dataset.
3. Split the dataset into training and testing sets.
4. Standardize the features.
5. Train the Perceptron model.
6. Generate predictions.
7. Evaluate accuracy and classification metrics.
8. Display the confusion matrix and actual-versus-predicted class distribution.

## Installation

```bash
pip install numpy pandas matplotlib seaborn scikit-learn
```

## Run the Program

```bash
python Lab_6_Perceptron.py
```

## Output

The program displays accuracy, the classification report, learned weights, intercepts, and two graphs. It also saves the graphs as PNG files.

## Result

The Perceptron Learning Algorithm is implemented and evaluated on the Iris dataset.
